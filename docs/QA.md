## 1. Chrome 网页取词

- **步骤**
  1. 打开 Chrome，在普通网页正文里双击选中一个英文单词（例如 `dictionary`）。
  2. 按 `Ctrl+Alt+D`。
- **期望**：250 ms 内在鼠标右下方出现卡片；词条、音标、方向徽章、来源词典正确；第一组释义展开，其余组折叠并显示命中条数。
- **结果**：

## 2. 记事本取词

- **步骤**
  1. 打开记事本，输入 `hello world` 并选中 `world`。
  2. 按 `Ctrl+Alt+D`。
- **期望**：卡片显示 `world` 的释义；卡片内文字可拖选复制。
- **结果**：

## 3. Word 取词

- **步骤**
  1. 打开 Word 文档，选中一个单词。
  2. 按 `Ctrl+Alt+D`。
- **期望**：正常弹出释义。若该 Word 版本不支持 UIA `TextPattern`，应显示可读的中文提示（而不是静默失败或崩溃）。
- **结果**：

## 4. PDF 取词

- **步骤**
  1. 用 Edge 或 Adobe Reader 打开一个文字版 PDF（非扫描件），选中一个单词。
  2. 按 `Ctrl+Alt+D`。
- **期望**：至少一种阅读器能正常取词；另一种若取不到，给出中文提示。不得崩溃。
- **结果**：

## 5. VS Code 取词

- **步骤**
  1. 在 VS Code 编辑器里选中一个标识符（例如 `serde_json`），再在终端/输出面板里选中一个单词各试一次。
  2. 按 `Ctrl+Alt+D`。
- **期望**：编辑器内取词成功并显示释义或“未收录”；终端内若取不到词，提示明确、不崩溃。
- **结果**：

## 6. 双屏且缩放不同

- **前置**：两块显示器缩放不同（如 150% + 100%）。
- **步骤**
  1. 在显示器 A 选中文字后按热键；再把鼠标移到显示器 B，在 B 上选中文字后按热键。
  2. 把卡片拖到屏幕右下边缘附近再次触发，检查是否翻转。
- **期望**：卡片出现在**当前鼠标所在显示器**的右下方，字号/尺寸符合该屏 DPI，不跨屏错位；靠近边缘时自动翻转到可见区域。
- **结果**：

## 7. 热键冲突

- **步骤**
  1. 用另一个程序（或第二个热键注册工具）占用 `Ctrl+Alt+D`。
  2. 启动 dict-popup，观察托盘提示；再进设置把热键改成被占用的组合。
  3. 改成可用组合（如 `Ctrl+Alt+F9`）后立即测试取词。
- **期望**：注册失败时给出中文错误（说明被占用），**旧热键保持可用**；成功修改后无需重启即可用新热键取词。
- **结果**：

## 8. 无选中文字

- **步骤**
  1. 光标放入记事本/浏览器输入框，确保**没有选中任何文字**。
  2. 按 `Ctrl+Alt+D`。
- **期望**：托盘气泡或卡片提示“未选中文字”之类的中文信息；不弹模态框、不崩溃、不产生空卡片。
- **结果**：

## 9. 词典文件被移动

- **步骤**
  1. 关闭程序，把 `stardict-ecdict-2.4.2.ifo` 改名或移到别处。
  2. 启动程序，打开设置 → 词典。
  3. 查询一个词；再把文件改回原名，重新打开设置。
- **期望**：该词典行标红“文件丢失/无法读取”，可删除或移除；其它词典仍可查询；程序不崩溃；文件恢复后重新添加即可使用。
- **结果**：

## 10. Explorer 重启后托盘图标

- **步骤**
  1. 程序运行中，执行 `taskkill /f /im explorer.exe`，再 `start explorer.exe`。
  2. 观察托盘区域，并用托盘菜单打开设置、触发一次取词。
- **期望**：托盘图标自动恢复（必要时重试添加），菜单与热键仍可用；不需要重启 dict-popup。
- **结果**：

- **期望**：第二次启动唤起设置窗口；托盘始终只有一个图标；不出现两个常驻进程。

## 12. 开机自启

- **步骤**
  1. 设置 → 行为 → 勾选“开机自启”，保存。
  2. 注销或重启 Windows，登录后等待托盘就绪。
  3. 取消勾选，再重启验证。
- **期望**：勾选后登录即自动运行（托盘就绪 ≤ 1.5 s，见第 14 项），不闪现主窗口；取消后不再自启，`config.json` 的 `behavior.autostart` 同步变化。
- **结果**：

## 13. 内存 < 100 MB

- **步骤**
  1. 正常使用 5 分钟（打开/关闭卡片、切换主题、查询若干词）。
  2. 执行：

     ```powershell
     powershell -NoProfile -ExecutionPolicy Bypass -File scripts\measure-memory.ps1 -Launch
     ```

     （默认 20 s、250 ms 采样、跳过 2 s 预热；也可对已运行实例不带 `-Launch` 直接采样。）
- **期望**：输出 `PASS`，且 max ≤ 100 MB；记录 min / avg / max 到本项结果里。
- **结果**：

## 14. 冷启动 < 1.5 s

- **步骤**
  1. 结束 dict-popup 进程（托盘退出）。
  2. 用秒表或如下命令计时：从启动进程到托盘图标可用（出现并能右键出菜单）。

     ```powershell
     $sw = [System.Diagnostics.Stopwatch]::StartNew()
     Start-Process dist\dict-popup.exe
     # 手动观察到托盘图标可用后：
     $sw.Stop(); $sw.Elapsed.TotalSeconds
     ```

  3. 连续测 3 次，取最大值。
- **期望**：3 次均 ≤ 1.5 s；不出现白屏/错误弹窗。
